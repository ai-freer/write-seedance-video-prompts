# Seedance 2.5 视频 Prompt Skill v0.1 Implementation Plan

> 本文是已完成的历史实施记录，不是安装指南，也不要求使用者安装额外的工作流 Skill。

> **历史说明：** 本计划记录 v0.1 Skill 骨架的原始实施过程。后续增加根 README，并将长期设计和历史计划迁移到 `docs/design/` 与 `docs/plans/`。公开准备阶段已将个人绝对路径改为通用路径；步骤和历史结果保留。

**Goal:** 建立一个可审阅、可验证、可持续迭代的 Seedance 2.5 路由型 Skill 初始骨架。

**Architecture:** 使用精简的 `SKILL.md` 作为流程路由器，按需读取一级 `references/` 文件；使用 `assets/project-template/` 承载项目级 Brief 与资产索引模板。v0.1 不实现自动生图或文件初始化脚本。

**Tech Stack:** Markdown、YAML、Codex Skill 标准结构、Skill Creator 验证脚本。

## Global Constraints

- Skill 名称固定为 `write-seedance-video-prompts`。
- 视频模型只支持 Seedance 2.5。
- 生图目标模型范围为 GPT、Gemini、Seedream、Grok Image。
- 主要角色必须通过已批准参考图资产锁定；文字身份规格只用于生成和校验资产。
- 原始运行时骨架不依赖 README；仓库发布阶段另行增加根 README 作为用户入口。
- 执行本计划时目录尚未初始化 Git；仓库初始化、提交和发布在计划完成后进行。

### Task 1: 初始化标准 Skill 外壳

**Files:**
- Create: `SKILL.md`
- Create: `agents/openai.yaml`
- Create: `references/`
- Create: `assets/`

**Interfaces:**
- Produces: 名为 `$write-seedance-video-prompts` 的 Skill 入口和 UI 元数据。

- [x] **Step 1: 运行官方初始化脚本**

Run:

```bash
python3 "$SKILL_CREATOR_DIR/scripts/init_skill.py" write-seedance-video-prompts \
  --path "$SKILL_PARENT_DIR" \
  --resources references,assets \
  --interface 'display_name=Seedance 2.5 视频 Prompt' \
  --interface 'short_description=规划资产、分镜并生成 Seedance 2.5 视频提示词' \
  --interface 'default_prompt=使用 $write-seedance-video-prompts 规划视频资产并撰写一份 Seedance 2.5 Prompt。'
```

Expected: 创建标准 Skill 目录、`SKILL.md`、`agents/openai.yaml`、`references/` 和 `assets/`。

上面的 `SKILL_CREATOR_DIR` 和 `SKILL_PARENT_DIR` 需由维护者设为实际的 Skill Creator 目录和目标父目录；这些开发工具不随本仓库提供，普通安装不需要运行初始化脚本。下文验证命令从仓库根目录执行。

### Task 2: 实现路由入口和核心参考文档

**Files:**
- Modify: `SKILL.md`
- Create: `references/workflow-router.md`
- Create: `references/project-assets.md`
- Create: `references/prompt-compiler.md`
- Create: `references/seedance-2.5-reference.md`
- Create: `references/image-asset-generation.md`

**Interfaces:**
- Consumes: 已批准的设计规格。
- Produces: 创作路径选择、任务路由、资产确认门、Prompt 编译协议和基础能力边界。

- [x] **Step 1: 用命令式语言重写 SKILL.md**

保留入口决策、必读 reference 路由、阻断规则和交付契约，使正文少于 500 行。

- [x] **Step 2: 写入多轴工作流路由**

定义创作流程、操作类型、生成策略、规划粒度、控制锚点和约束模块，明确哪些选择互斥、哪些可组合。

- [x] **Step 3: 写入项目与角色资产规则**

定义统一视觉规格、核心角色参考资产、场景 Look、单次参考包、普通次要人物和资产状态。

- [x] **Step 4: 写入 Prompt 编译与官方事实基线**

记录条件模块、编辑/延长/转场协议、Seedance 2.5 已确认参数和稳定性建议。

- [x] **Step 5: 写入生图资产适配契约**

定义 GPT、Gemini、Seedream、Grok Image 的单目标模型选择方式；未验证的模型专属语法不得写入 v0.1。

### Task 3: 创建项目档案模板

**Files:**
- Create: `assets/project-template/project.yaml`
- Create: `assets/project-template/asset-registry.yaml`
- Create: `assets/project-template/brief.md`

**Interfaces:**
- Consumes: 项目与资产 reference 中定义的字段。
- Produces: 可复制到新视频项目中的最小档案模板。

- [x] **Step 1: 创建 project.yaml**

包含项目身份、创作流程、视频参数、操作类型、生成策略、规划粒度和 Gate 状态。

- [x] **Step 2: 创建 asset-registry.yaml**

包含角色、Look、场景、道具、音频、参考视频和单次 Seedance 映射的空数组结构。

- [x] **Step 3: 创建 brief.md**

包含创作目标、故事、受众、视听方向和已确认决策，不加入不适用于所有项目的内容。
