- [官方手册](https://bytedance.larkoffice.com/wiki/RXh5ww6EqighMdkVTMccm2d4n7e)当前读取修订为 8839；旧 Skill 记录为 8540。

- 本轮核对了参数、交互、提示词建议及案例文字/评价；未逐个播放成片，也没有自行生成。明确参数、稳定建议、示例目标与展示评价分开记录。

## 2. 保留什么，改变什么

保留单一 Seedance Router、快速/长精细双路径、六个正交控制维度、四个确认门、项目级资产档案、角色身份与 Look 分层，以及统一视觉规格 + 单一图片模型适配。

| 更新点 | 旧规则问题 / 覆盖缺口 | v0.2 处理 |
| --- | --- | --- |
| 基础结构 | 把“全局补充（结尾）”理解成最终画面 | 情节终态与放在末尾的全片要求分开 |
| 续写 | 默认人物/服装/场景全不变，混淆追加时长 | 一镜到底与切镜分别编译，明确允许变化；源片/新增/最终时长和计时基准分开 |
| 快速角色资产 | 入口最低包与生图模块强制多视图冲突 | 快速包不强制多视图；仅保留源片人物的编辑不重做人物图 |
| 候选 demo | 允许候选，但正式阻断规则未区分 | 单次引用包记录使用许可，候选状态不升级；草稿和执行包分清 |
| 控制精度 | 个别要求过于一刀切 | 支持故事与关键时间码混合、转场候选选择、超长直出及有意硬切/超现实规则 |
| 表演与物体 | 人物形容词多，缺少递进和非人物公式 | 动作+潜台词+触发，稳定身份与临时表情分层；物体用数量/设计/材质/辨识特征 |
| 局部参考 | 只有素材“用途” | 增加必要排除项及源选段/目标范围，防止局部动作影响全片 |
| 多人/多视图 | 主体数、图片数与库中人数容易混淆 | 按当次主体数选择独立视图与最小上传包，保留官方建议的适用条件 |
| 编辑与白模 | 单一保持项模板不够用 | 区分声音、视角、局部、绿幕/合成；粗模动态骨架与细模渲染分别写 |
| 声音/语言/文字 | 全局禁令可能抵消指定内容 | 音色与内容绑定；对白、字幕、画内字、Logo例外分开 |
| 项目状态 | 只有空集合，缺少实际字段契约 | 实体文件登记、角色/Look关联、引用包、片段入出状态与确认依据；受影响项才回退 |
| 案例与证据 | 案例尚未整理，容易照抄冲突 | 18类可迁移模式及冲突清单；不承诺官方展示“无损/完美” |

本轮自检还修正了“没有图片就删素材段”的表述，避免误删纯音频/视频参考；首帧/首尾帧的界面角色与普通素材引用分开说明。

## 3. 文件职责与复杂度控制

- `SKILL.md`：保留短入口，细节继续按需路由。
- 原有 5 份 reference：分别维护路由、资产、编译、官方事实和图片适配；不复制完整手册。
- 新增 `references/case-patterns.md`：只存案例模式、来源定位与复用风险；不是成片素材库或案例数据库。
- 3 份项目模板：兼容增加可选字段，保留 `schema_version: 1`；旧目录、ID、未知字段和批准版本不自动改写。
- README 与总体设计：同步入口与决策理由；具体参数以官方速查为唯一维护位置，字段以资产文档为准。
- 本记录用于维护审计；v0.1 实施记录保持历史原样。没有新增工作流、状态引擎、生成工具、安装流程或重抽机制。

## 4. 离线前向验证

独立测试仅获得当前 Skill、以下原始请求及明确的只读/不生成边界，未提供预期答案或本轮修正清单。主 Agent 逐项阅读了实际答复。

| 输入场景 | 实际观察 |
| --- | --- |
| A：只说“帮我做一个香水视频” | 先问快速或精细路径，没有展开其他问卷 |
| B：12秒竖屏快速人物demo；两张候选图获本次许可；不建档，只要草稿 | 不要求补多视图或正式批准；区分拟上传映射与真实附件；候选身份不被升级 |
| C：90秒16:9/720p直出，Brief/主角/两套Look已确认，讨论下一步 | 进入分镜讨论，尊重直出，不强制拆段或重问已批准项；仅追问含混的中文声音形式 |
| D：18秒访谈只去BGM，保留对白/环境/现有字幕/画面 | 走声音编辑，不重建角色图；去BGM不变静音，不删已有字幕，不承诺逐帧无损 |
| E：20秒源片新增10秒，关门后切到次日车站、换批准旅行装 | 核算20+10=30，以新增段0–10秒编排；允许切景换装，皮箱和身份保留 |
| F：12秒白模只管比例站位，8秒动作片只影响成片20–25秒 | 视频合计20秒；源素材区间与目标区间分开，未把短参考的20–25秒当源截取点；不擅编反击招式 |
