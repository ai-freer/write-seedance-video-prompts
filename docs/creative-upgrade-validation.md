# v0.3 创作升级与验证边界

## 改了什么

在既有官方能力编译器上补充镜头任务、空间/表演分层、参考职责、选择性试拍和粗剪反馈。详细方法与来源集中在 [创作与迭代](../references/creative-direction.md)，入口按需加载，不复制到每个模板。

独立项目仍可用原模板；工作台项目沿用其唯一主档，由工作台 Skill 映射现有对象。没有新增状态 schema、确认门、模型参数、自动生成/重抽或工作台 API；图片模型适配和官方能力数值保持原基线。

## 场景检查

以下为规则逐项审阅，不是独立 Agent 实跑或视频生成测试：

| 场景 | 本版应采取的决策 |
| --- | --- |
| 用户已选快速、单次虚构机器人短片 | 沿用选择，以反差/动作编译，不强加人物多视图、全流程分镜或试拍批次 |
| 同一主角跨场换装 | 身份参考不变，选择本场 Look；未来包显式更新版本，原执行保留 |
| 反打后人物屏幕左右变化 | 对照世界坐标与机位，不能把屏幕左右不变当作绝对连续性 |
| 只去掉 BGM | 沿用编辑协议、保持对白和环境声，不进入新片创意问卷 |
| 单镜可用但粗剪拖沓 | 先评估选段/顺序/叙事任务，不默认重抽 |
| 任务未知或授权预算已用尽 | 查询原任务或停止新提交，不把持续工作理解为无限付费授权 |
| 工作台已有项目与对象 | 复用对象、引用版本与档案接口，不复制默认 YAML 主档，不伪造执行与批准 |
