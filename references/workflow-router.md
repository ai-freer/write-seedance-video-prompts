# 工作流路由

本文件决定“如何做”，不直接写最终 Prompt。按顺序选择各维度；这些维度彼此正交，不要把故事规划方式、参考素材和模型操作混为一个单选项。

## 1. 入口路径

| 路径 | 适用条件 | 默认交付 | 确认强度 |
| --- | --- | --- | --- |
| 快速短片 | 快速概念验证、简短 demo、低资产复杂度 | 单个生成包 | 只确认高影响项 |
| 长视频 / 精细制作 | 超过 30 秒，或人物/产品/动作/镜头要求严格 | 分阶段生产包 | Brief、资产、分镜、终包四门 |

若用户说“先试试看”“出一个方向”，推荐快速短片；若提到多场景、多 Look、连续叙事、产品精确展示、复杂对白或高重抽成本，推荐长/精细路径。最终由用户选择；已明确选择、目录和批准记录不重复询问。短片也可以走精细路径；不为单纯修改已有 Prompt 重走立项。

## 2. 操作类型

| 操作 | 输入重点 | 核心控制 |
| --- | --- | --- |
| 从零生成 | 图片/视频/音频可选 | 故事或时间轴、主体、镜头、声音 |
| 续写 | 一个符合延长入口限制的源视频 | 源片末态、新增时长、一镜到底或切镜、保持项与允许变化 |
| 编辑 | 待修改视频，可带参考图 | 目标对象、A→B 改动、生效时间、保持项 |
| 组合 / 无缝拼接 | 两段或多段源视频 | 先区分普通后期剪辑与模型生成过渡，再决定保留区间及转场控制 |

先判断操作类型，再决定是否需要首尾帧、创意参考、白模、分镜格或其他锚点。

## 3. 生成策略

| 策略 | 建议场景 | 主要代价 |
| --- | --- | --- |
| 单次 4–30 秒 | 一个完整短片或单一段落 | 低成本，局部可控性有限 |
| 30–180 秒超长直出 | 连续叙事、长访谈感或不宜切断的表演 | 一次生成成本高，局部返工代价高 |
| 基础片 + 续写 | 先确认开局，再延长至约 60 秒 | 接续处和累计漂移需检查 |
| 多段生成 + 拼接 | 多场景、多 Look、高控制要求 | 资产和连续性管理更复杂 |

快速路径优先单次生成。长路径优先分段是成本管理偏好，不是官方限制。用户希望直接生成长片时，比较直出的表演连续性与分段的局部返工优势，尊重其选择，不强制改成分段。

续写应分别记录源片、新增、最终时长；不能对已超过入口限制的累计成片无限追加。普通后期拼接不受“一次模型输入素材”的总时长限制，但模型生成过渡需要遵守该限制。具体数值统一见 `seedance-2.5-reference.md`。

## 4. 规划粒度

从最低足够粒度开始，风险上升时再升级。

| 粒度 | 写法 | 适用 |
| --- | --- | --- |
| 意图驱动 | 一句话概览 + 大体故事线 | 情绪片、自然表演、允许模型编排 |
| 节拍驱动 | 按叙事 beat 描述发生顺序 | 有明确转折但不需要逐镜头 |
| 镜头驱动 | Shot 1/2/3，写构图、动作、运镜和转场 | 广告、产品、动作连续性、多场景 |
| 精确时间轴 | `0–3s`、`3–7s` 等区间 | 卡点、产品 reveal、对白同步、严格时序 |

出现指定秒数事件、严格因果交互、对口型、精确展示或镜头不可重排时，补足对应控制，不必把整片都升级到逐秒。允许混合：前段用故事节拍，只有产品 reveal 或关键反击用时间码。人物表演可写“心理变化 → 可见动作 → 触发事件”，不必逐秒规定每个微表情。

时间码是强引导，不是绝对帧级保证。若精确性不可妥协，拆成更短片段分别生成和验收。

## 5. 控制锚点

按任务需要组合，不要求全部使用：

- **标准角色资产**：锁定主要人物身份；
- **场景 Look 资产**：锁定服装、妆发和当前状态；
- **首帧 / 尾帧**：锁定起止构图、姿态或视觉结果；
- **动作参考视频**：参考动作节奏、表演或运镜；
- **创意参考视频**：迁移广告结构、视听语言或节奏，不默认复制主体；
- **多宫格分镜**：线稿/火柴人也可用；每格是一幅完整镜头，不是单个人物素材，正式外观另行绑定；
- **白模视频**：粗白模提供动态/空间骨架并映射目标资产；细白模为完整动画做渲染/材质/光影替换。具体参考哪些维度由任务决定，不自动照搬全部动作；
- **音频**：控制对白、音色、节奏、环境声或音乐结构。

每个锚点说明参考职责与必要排除项。只作用于局部时，分别写清源素材选段和成片生效范围，例如“@视频2 的动作只用于成片 20–25 秒”。不要把这句话误读为截取源视频的 20–25 秒。不同参考冲突时分配职责或撤去其中一个，不自行发明权重参数。

## 6. 约束模块

最终 Prompt 按需选择：

- 角色身份与 Look；
- 场景、时间、天气和光线；
- 动作、物理关系和因果顺序；
- 构图、镜头焦段感、机位和运动；
- 声音、对白、语言、音色和节奏；
- 镜头内和镜头间连续性；
- 需要保持不变的元素；
- 必要的负向约束。

编辑按目标补充协议：局部增删改、声音分离、空间视角、绿幕背景/前景合成；不为它们新增独立工作流。转场可由模型从适合的候选中选择，只有高控制镜头才细化触发与运动匹配；有意硬切是合法镜头语言。

不因模板中存在某个模块就强行填写。重复、冲突和无关修饰会降低指令主次清晰度。

## 7. 路由顺序

1. 确定用户选择的快速或长/精细路径；
2. 加载或创建项目档案；
3. 判断操作类型；
4. 选择生成策略；
5. 选择规划粒度；
6. 选择必要锚点；
7. 用粗略故事/镜头需求识别资产缺口和风险；
8. 进入 Prompt 编译。

## 8. 长路径四个确认门

### Gate 1：Brief

确认目标、受众、交付时长/画幅、核心表达、叙事范围、声音策略和不可改变项。

### Gate 2：资产

先有足以识别需求的故事/镜头草案，再确认本轮需要的标准角色资产、Look、产品/场景/道具、声音和参考视频。不是在分镜需求未知时先制造完整资产库。纯声音编辑等任务可由已确认源视频满足资产门。

### Gate 3：分镜

确认段落、镜头或时间轴，检查场景切换、人物出入、服装变化、动作因果和声音连续性。

### Gate 4：最终生成包

确认生成设置、上传顺序、素材映射、最终 Prompt、风险和分段生成顺序，再执行高成本生成。

确认门使用 `pending / approved / skipped_with_risk / blocked`。记录确认范围和依据；发生改动时，只重开受影响的门，例如换 Look 重开相关资产/分镜/终包确认，不必重问已定受众。确认生成包与授权执行生成不是同一件事。
