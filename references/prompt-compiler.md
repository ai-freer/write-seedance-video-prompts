# Seedance 2.5 Prompt 编译器

把 Brief、资产和操作类型编译为可执行生成包；输入未齐也可写明示缺口的草稿。按当前操作读对应小节，不填完整字段表。

导航：基础生成/表演 → 续写 → 编辑 → 转场/拼接 → 多宫格/白模 → 声音与文字 → 预检。

## 1. 共享结构与引用

```text
素材映射（有素材才写）
一句话概览
故事线 / 节拍 / 镜头 / 时间轴（可混合）
全局补充：贯穿全片的必要保持项、声音与排除项
```

故事最后一幕属于情节；“全局补充（结尾）”指 Prompt 末尾的全片规则，两者不能合并。人物、Look、场景、动作、镜头、表演按需要嵌入相应层，不重复描述图片已经清楚表达的外观。

每次建立明确上传映射，稳定资产 ID 与本次上传编号分开。复杂参考可拆成：

- 用途：身份 / Look / 动作 / 空间布局 / 相机路径 / 风格 / 音色 / 音乐等；
- 排除：不得继承的人物、环境、外观、动作等，仅写必要项；
- 源素材选段：要引用原素材哪一段，未限定则省略；
- 目标范围：只影响成片哪个镜头或时间段，未限定则作用于本片；
- 时间基准：片段内、源片内或整片，不能混写。

例如：“@视频1 只约束双方体型差、站位方向和拍摄距离，不复制动作。@视频2 的动作只用于本片 20–25 秒，其余段落不参考；替换为已指定的角色与环境。”这里的 20–25 秒不是源视频截取点。一个参考同时管多个维度仅在确实需要时使用，不臆造数值权重。

## 2. 基础生成：最低足够规划

### 故事 / 节拍驱动

```text
@图片1作为主角身份参考，@图片2只定义本场Look。
一支[目的/题材]短片，在[环境]里，[主体]经历[核心事件]。
[按因果描述行动、转折和情绪落点；允许模型安排镜头和节奏。]
结尾：[若有重要终态，写清动作或构图，不另造一套全局规则]。
全片要求：[必要的视觉/声音保持项及排除项]。
```

没有任何参考素材才删掉素材段；仅音频或视频参考也可保留对应映射。主要人物需要长期一致时先走资产流程，次要人物可以用下文文字描绘。

### 时间轴 / 混合规划

```text
[素材职责与一句话概览]
0–4秒：[建立状态、一个主要动作及镜头目标]。
4–10秒：[由前段结果触发的转折；可留出表演空间]。
10–12秒：[需要定时发生的产品展示/动作高潮及声音]。
12–15秒：[收束到终态]。
全局补充：[声音、风格和真正全程成立的约束]。
```

按实际时长调整，不套用示例秒数。重要事件写时间码，其余可以写顺序；需要完整时间轴时覆盖时长且无互斥事件。动作密度过高先减同时事件或拆镜头，不仅压缩文字。每段优先一个主动作和镜头目标，动作链确有需要时写清准备、接触、结果，不能机械限制动作数。

### 表演与人物文字

表演重点镜头用“阶段意图 → 可见动作 → 触发/变化”，必要时补一两句潜台词：
“她听见列车鸣笛后停止追问，视线移向站台，嘴角短暂上扬又落下；这不是开心，而是在努力让告别显得轻松。列车启动后才让泪水落下。”

情绪的起点、递进与释放点分开；不要同时要求开场落泪和全程强忍。没有强表演需求时无需微表情清单。

次要人物按需要选择：
```text
[年龄/族裔与骨架]，[肤色/肤质]，[有辨识度的面部结构]，
[眼神意图]，[发型及状态]，穿[剪裁、材质、颜色、使用痕迹]，[体态/动作习惯]。
```
强辨识人脸可具体到 3–4 个面部标志；背景路人不用全填。镜头里已写的视线/构图不重复塞进肖像。角色稳定身份、场景 Look、临时表演状态分层；不得用长篇人物文字替代正式主角参考资产。

产品/道具可写“数量 + 颜色 + 形状/设计 + 物品 + 材质/磨损 + 标志特征”。Logo、刻度、零件数量等准确性另作验收项。

### 首帧 / 首尾帧

在支持的入口指定起始图与结束图的角色，Prompt 说明起点如何到达终态、必须保持什么、允许怎样变形/运镜。只给首帧就不虚构尾帧。人物/Look/物体冲突先解决，再讨论过渡；有意的变形则写清触发与目标。上传角色以当前界面为准，不把普通参考编号冒充已设置的首尾帧槽位。

## 3. 视频续写

先区分：
- **一镜到底**：保留原片末态的动作、机位运动、空间和声音，并从下一状态继续；
- **切镜/转场**：保持指定身份与叙事线索，允许明确安排的新场景、新角色、Look 或景别变化。

```text
从@视频1末尾向后延长[新增 N 秒]。下面时间均以新增段起点为0秒。
原片末态：[必要的动作/道具/站位/声音信息]。
连接方式：[一镜到底，或选定/可选的切镜转场]。
新增段：[0–N秒故事或时间轴；切景时说明叙事连接与新状态]。
保持：[真正跨接点稳定的元素]。
允许变化：[有需要才写新场景/Look/人物/光线/机位]。
终态：[新增段最后状态]。
全局补充：[新增段的必要声音与负向约束；不重演已完成动作]。
```

分别列源片 S、新增 N、最终 S+N；默认 Prompt 使用新增段相对时间 0–N。用户给整片时间码时换算并标注，不同时混用；原片内容无需再作为新增剧情生成。支持范围见官方速查，当前成片超过续写入口限制时不能无限“套娃”。

切镜续写不套用“所有人物、场景和服装完全不变”。有意换装写清旧 Look 结束与新 Look 开始；衣服渐变本身是剧情时描述触发和变化过程。

## 4. 视频编辑：按修改目标选择保持项

```text
编辑@视频1，在[全程/源片第X–Y秒/某事件以后]，
将[可识别的目标 A]改为[目标 B]。
[有参考素材才写其职责。]
保持：[不应改变的画面、动作、声音等]。
允许随改动调整：[有需要才写，例如新视角造成的遮挡/投影变化]。
```

标注编辑额外写实际工具、颜色、位置内外、具体对象，并沿用界面“添加至输入框”产生的帧时间标签；标注帧定位与修改持续区间不同，二者都核对。没有真实标注时用语义定位，不假装已经圈选。

| 子类 | 必要差异 | 验收重点 |
| --- | --- | --- |
| 局部增删改 | 对象、范围、A→B、时序、范围外保持项 | 边缘残影、遮挡、反射、后续帧及意外连带变化 |
| 仅声音修改 | 指定移除/替换哪层，保留哪些声音与画面 | 不能把去 BGM 写成静音；检查对白、环境声和音效损失 |
| 空间视角修改 | 新观察方向、距离/高度、目标构图；保留身份和世界相对位置 | 投影、遮挡、反射应合理变化，不能同时固定原机位/全部像素 |
| 背景换场景/绿底 | 保留前景边缘与动作，明确背景替换目标 | 发丝/透明物、绿边、光照；纯绿底不等于透明视频 |
| 前景视频合成 | 前景/背景职责、出现时间、比例、落点、遮挡及光影 | 滑步、漂浮、边缘溢色、透视和声音混入 |

去 BGM 的简例：“编辑@视频1，全程仅移除背景音乐；保留原对白、环境声和音效，画面内容、时序及现有字幕不作修改。”不改变人物时可复用源视频作身份依据，不要求先生成无关角色设定图。

“保持”是目标不是质量保证；需要原画面逐帧不变的音频处理或剪辑，应提示非生成式后期处理更合适，不自动代为执行。

## 5. 转场与拼接

先判断是普通剪辑还是需要模型生成桥接。普通组接交付剪辑顺序/衔接建议即可，不把整部长片塞进模型；需要桥接时选相邻片段，并检查单次总输入时长。

| 转场意图 | 可选方式 | 精细控制时补充 |
| --- | --- | --- |
| 清楚叙事 | 自然切镜、节奏明确的硬切 | 切点、叙事连接、切后景别 |
| 时间/情绪过渡 | 淡入淡出、叠化 | 两端状态、时长、声音接续 |
| 节奏冲击 | 白/黑闪、动作甩镜 | 节拍、运动方向与切后落点 |
| 空间/形态桥接 | 划像、遮罩、相似物、动作接力、缩放 | 遮挡/形状/动作匹配及进出状态 |
| 风格化转换 | 水墨等 | 风格规则与需要保留的主体 |

低精度任务可让模型从候选方式中选适合的一种，给清楚的两端内容和保持项；高精度才指定触发机制。硬切不等于错误，遮挡也不必变黑。

```text
用@视频1的[末段范围]与@视频2的[开头范围]生成连接。
两端需要保留：[身份、关键内容及风格]。
在[触发点]通过[方式/候选转场]进入下一场；
[必要的运动、构图或声音匹配]。
不引入无关中间情节。
```

模型生成可能改动两端，不能承诺“完整无损保留”。若要求原片一帧不改，保留两端原文件，把生成限制在过渡段后再组接。选段的实际文件、截取点和重新编号要与上传包对应。

## 6. 多宫格与白模

### 多宫格

逐格说明阅读顺序、每格完整镜头的构图/动作；线稿或火柴人可用于规划，主体外观和最终风格另用标准资产绑定。说明格间需要补全的运动或切镜，不输出固定分屏，除非用户要分屏片。

```text
@图片1是按[行优先/明确格序]阅读的分镜草图，不是最终画风。
第1格：[镜头内容]；第2格：[镜头内容]……
主角/Look参考[已上传资产]。按格序展开，补全[必要的桥接动作或切镜]。
```

### 粗白模：空间/动态骨架

```text
@视频1仅参考[轨迹/机位/站位/光影/切镜中的所需维度]，不参考灰模外观。
其中[颜色/几何形状代理]对应[角色/物体的图片引用]。
[按段写剧情与完整动作序列、场景替换及全片收束要求。]
```

不是所有粗白模都应照抄动作；只有布局用途就明确排除动作。有肢体/翅膀代理时补完整动作，优先简化不必要的代理肢体。

### 细白模：完整动画的渲染

```text
将@视频1的模型动画渲染为[目标视觉风格]。
保留[已确认的几何关系/动画/相机路径]；
[按需分段指定材质、色彩、光照，绑定角色/产品/场景参考图]。
全片保持[核心结构与统一视觉规格]。
```

先去掉参考视频中的辅助线、坐标轴、相机示意等。多个参考作用不同或只作用局部时使用第1节的范围约束；不要为了时间切片重置每段起始站位。先判断任务是动态重创作还是渲染已有动画，不只按“粗/细”标签机械决定所有保持项。

## 7. 声音、语言和画内文字

仅填写相关项，但要区分：

- 角色 → 音色参考绑定；台词内容参考、音色参考、音乐/节拍参考彼此独立；
- 对白语言/口音、台词与情绪、发生时间或触发点；Prompt 用中文不代表对白必须中文；
- 环境声、拟音、音乐的保留/替换/禁用及进出；
- 字幕是否需要、用什么语言；已有字幕是否保留；
- 画内文字/Logo/标签的允许清单、语言与禁用范围。

例如，指定保留瓶身品牌时，写“保留瓶身指定 Logo，不新增字幕或其他文字”，不能再加全局“禁止任何 Logo/文字”。原语言限制与明确的外语台词冲突时先确认是否为例外，不擅自翻译台词。科普/教程需核对计数、因果顺序和标注对应关系。

负向约束只针对当前可观察风险；优先写正确动作和保持项。不要用通用“物理必须真实”抵消用户有意的悬浮、变形或水墨等规则。

## 8. 交付与预检

每个生成包交付四项：生成设置、实际上传映射、可复制 Prompt、预检结论。草稿与执行包分清，不在可执行 Prompt 中留下假编号或缺失文件占位。

设置含操作/策略/模式、demo 或正式用途、时长/画幅/清晰度、规划粒度；续写另列 S/N/S+N 和计时基准。无素材任务省略上传映射。多段项目按需记录入段/出段状态（Look、位置、持物、动作、情绪、声音等），为后段复用；不强迫简单 demo 填连续性账本。

预检分层处理：

- **必须解决才能发正式包**：文件/批准依据缺失、@引用冲突、硬性输入超限、重要时长/语言等互相矛盾。候选素材经本次 demo 授权可用，不冒充正式资产。
- **需提示与选择**：超过稳定建议、多人接触、精确文字/产品、长片返工、局部编辑副作用。给最小改善方案，不把风险当禁令。
- **按操作检查**：续写计时与连接类型；编辑保持项是否与改动冲突；转场是否需要生成；参考范围是否越界；时间轴是否有互斥事件或空档。
- **冲突清理**：故事终态与全片要求分开；角色/Look/音色绑定一致；全局声音/语言/文字规则与局部例外一致；技术设置不从“8K、60fps”等审美词推导。

交付中标注已满足、假设、风险、待确认及验收重点。没有实际生成和观看成片时，只能说 Prompt/规则已预检，不能说视频效果已验证。
