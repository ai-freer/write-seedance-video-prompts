# 创作与迭代：让镜头完成任务

本文件用于创意展开、精细镜头与成片反馈。只改已有 Prompt 时读取对应小节，不增加立项问卷。导航：创意 → 空间/表演 → 资产 → 编译示例 → 试拍/剪辑 → 来源。

## 1. 从观众体验倒推控制

先沿用 Brief，补一句“观众将从什么状态走向什么理解/感受”。有叙事时看信息、关系或处境如何变化；情绪片、教程、产品片也可以以感受、理解或辨识为目标，不强塞冲突与反转。

关键镜头可在现有分镜中写四项，不新增强制表单：

- **任务**：交代空间、透露线索、展现关系、揭示产品能力，或让观众停留在某种感受。漂亮画面不是唯一验收标准。
- **可见证据**：靠哪个动作、物体、构图或声音实现；“孤独”“高级”要落到可观察选择。
- **变化与连接**：起点、触发、结果；接前段什么状态，向后段留下什么。
- **自由度**：哪些必须发生，哪些交给模型安排。节拍清楚即可时不硬写每秒。

先判断镜头是否必要：与相邻镜头表达完全相同且无节奏作用时，可删减或合并。需要延续的情绪停顿可以保留，不以事件数量衡量全部作品。

## 2. 空间、行为与声音分层

多人互动或跨镜头接续时，区分三层：世界布局（门、柜台、人物相对位置）、当前状态（持物、朝向、接触点）、相机投影（从哪里看，谁在画面哪边）。用少数稳定地标建立坐标；换机位后屏幕左右可能变化，不能要求世界与画面坐标同时不变。

需要方向连续时说明轴线与视线目标；有意越轴、遮挡或反向运动可保留，只要交代观众如何重新定位。复杂布局可以用参考图/白模承担，别用长篇文字重复图中信息。无需每镜强制先拍一秒全景。

人物分成稳定习惯、场景情绪、瞬时反应：例如平常说话克制，本场隐瞒焦虑，听见门响后手指才停止敲桌。不要把每一拍都固定成同一个表情。非人角色用其结构能表现的动作：机械头偏转、灯带变化，而非默认人类瞳孔微表情。

有对白时分清说话者与听者，标明实际说出的台词，导演意图不混进台词。声音连续性区分角色音色/口音、当前语气、对白内容及环境底声；多段一致音色需合适参考或后期方案，单靠文字不能保证。动作场面写清施力者、接触对象、反应和结果，避免同一时刻堆叠无法兼容的动作。

## 3. 资产为镜头服务

先识别当前镜头的失败风险，再选最低足够参考：身份、Look、空间、姿态、动作或声音。每张图说明职责和不继承项。标准角色参考尽量便于识别真实结构，场景光线由当前镜头决定，避免把设定图的摄影条件误当永久规则。

跨段重要的湿衣、破损或持物变化，必要时派生状态参考并确认继承关系；单次小表情通常写 Prompt 即可。不要强制所有角色都准备去头全身图、所有角度或所有情绪图。原图清楚、当前镜头不需要更多控制时直接复用。

## 4. 两个原创编译示例

以下只演示决策与文字，不是已生成的 good case，也不是第三方原 Prompt。时长为创作意图，正式提交仍核对当前入口。无已确认素材的例子不能冒充稳定主角资产包。

### A. 快速概念：平静行为与环境反差

输入：12 秒复古机械维修工在废弃温室喝茶，趣味而非恐怖；单次新虚构角色，无跨段身份要求，用户已选快速路径。

创作任务：先让观众读到平静日常，再发现环境与行为不相称。反差通过画面揭示，不靠“震撼、电影级”叠词。

Prompt 草稿：

> 废弃温室内，一台旧式黄铜维修机器人坐在窄桌旁喝茶，安静而略显荒诞。近景从它轻放茶杯开始，瓷杯与金属手指短促碰响；镜头缓慢后移，露出被藤蔓包围的空椅子和破裂玻璃屋顶。水滴落入桌旁水桶，机器人把茶杯向内挪开一点，继续端坐。柔和阴天光贯穿全段，磨损金属与潮湿植物采用统一写实质感；保留滴水、杯碟与轻微机械声，无对白、背景音乐或新增字幕。镜头节奏允许自然安排，总长约12秒。

验收：后移真正揭示环境；挪杯由落水触发；金属手与杯子接触可信。不要同时写“全程特写”和“展示整个温室”，也不把“无 BGM”扩大为静音。简单 demo 无需空间地图与试拍批次。

### B. 精细叙事：隐瞒通过动作显露

输入：同一主角跨段；此段是雨后咖啡馆换装场景，前段已拾起信封。正式编译前需已批准身份图和本场湿外套 Look；下列引用仅为教学假设，实际编号按上传重建。

先定空间：门在柜台后方，信封在她右手；机位朝向柜台，门处于画面后景。镜头任务是让观众察觉她在藏信，而不是泛泛表现“紧张”。

> @图片1仅作主角身份参考，@图片2定义本场湿外套与发型，不沿用其背景。雨后的咖啡馆内，她站在柜台前，右手把信封压在台面，门在她身后的后景。先保持能看见右手和上半身的中景。听见开门铃，她将信封滑入外套右侧口袋，随后才转头向来人，露出勉强维持的微笑。镜头在藏信结束后缓慢靠近脸部，避免提前把关键手部动作切出画面。她不说话；保留开门铃、衣料摩擦和低声室内环境音，不加背景音乐或字幕。结尾信封已在右侧口袋，右手自然垂下。

交接说明不塞进 Prompt：下一段须沿用新 Look 与信封在口袋的状态；如需对白重叠作剪辑衔接，另外约定可裁切的声音/画面余量，不自动重复台词。若藏信与反应来不及，先调整镜头密度或拆包，不靠增加形容词解决。

## 5. 试拍、看片与迭代

精细项目可选最能暴露风险的代表镜头先试：近景对白、复杂接触、跨 Look 或关键产品展示。选片依据是能否验证后续共同假设，不强制固定数量。试拍需要真实生成授权与预算；只做 Prompt 时交付测试建议，不提交任务。通过一个镜头不能证明所有场景稳定。

计划生成时长、实际输出时长、剪辑使用时长分别记录。需要剪辑余量时预留动作前后停顿、反应或声音衔接，但无通用“额外几秒”要求，不超过入口限制。剪辑精度最终由实际素材与后期完成，不承诺 Prompt 帧级控制。

实际观看后记录问题时间点与证据，再分类决定下一步：

| 问题 | 优先检查 / 改动 |
| --- | --- |
| 主角/服装漂移 | 引用版本、职责冲突与必要状态资产，而非堆身份形容词 |
| 站位/接触混乱 | 世界坐标、机位、动作链或空间参考，必要时拆分复杂动作 |
| 表演或揭示无效 | 触发、可见证据、景别是否遮住关键动作 |
| 单镜好看但组接不成立 | 前后状态、重复信息、视线/节奏、声音与选段；可能应改分镜而非重抽 |
| 仅需裁切、混音或精确文字 | 非生成式后期是否足够；未经授权不代为执行 |
| 任务/下载结果未知 | 查原任务、取回同一结果，不重新收费提交 |

先判断可保留、可裁切还是需重制。返工写一个主要假设及预期改善，尽量固定无关条件，保留旧 Prompt、参考版本和候选；模型随机性意味着这不是严格因果实验，也不保证只改变指定局部。已有预算用尽、同类失败反复且没有新假设、或需要超范围重制时停止提交，给出减复杂度、补参考、改镜头或后期的选择。没有通用重抽次数；不因“未完工”自动持续扣费。

先做可判断的粗剪再批量精修；反馈可上溯到故事与镜头，而非默认所有问题都由 Prompt 解决。单镜技术可用、实际观看、创作通过和整片通过分别表述。
