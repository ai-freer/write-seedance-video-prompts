# 官方案例的可迁移控制模式

按任务选最接近的一两项，不把所有案例规则塞进一个 Prompt。这里是手册案例的提炼与本 Skill 的应用建议，不是官方原文模板，也不是本项目实测评分。

来源：[官方手册](https://bytedance.larkoffice.com/wiki/RXh5ww6EqighMdkVTMccm2d4n7e)，2026-09-06，修订 8839。章节定位使用手册标题，案例用内容关键词定位；历史差异与观看范围见 `seedance-2.5-reference.md`。

## 1. 按控制目标选案例

| 需求 | 官方章节 / 案例定位 | 可迁移的方法 | 在本 Skill 中如何用 |
| --- | --- | --- | --- |
| 一个清楚动作的短片 | 二 → 基础提示词；湿地丹顶鹤 | 全局环境/机位与展翅、跳跃、落地动作分开 | 简短故事或时间轴；不为环境展示建立人物资产库 |
| 人物有辨识度 | 二 → 生成真人人物怎么写？ | 肤质、骨相、眼神、发丝、衣料状态共同塑造角色 | 次要人物按需文字描写；主要人物先用于制图与验收，不当作图像身份锚点的替代 |
| 情感近景 / 微表演 | 二 → 30秒长视频怎么写？；29秒江边告别 | 分阶段写动作和心理含义，限制情绪过早释放 | 设定表演核心与变化触发；只在需要的位置加时间码，不照抄示例的所有微表情 |
| 长故事与氛围片 | 二 → 超长视频怎么写？；旧图书馆/月光狐狸、咖啡馆雨景 | 明确核心世界、情绪走向和终态；情节密度因题材而异 | 连续表演或氛围片可直出，多场景高返工项目可分段；先完成所选路径的确认 |
| 定时 reveal / 动作因果 | 三 → 时间戳文本控制；以及30秒公式 | 分段指令控制事件顺序和视听协同 | 整体故事 + 关键区间混合编排；生成设置与时间码统一，精确性需验收 |
| 多人身份/服饰独立 | 三 → 多人参考升级；同学聚会、婚庆、舞台、四人舞蹈 | 逐人绑定素材、站位、出入场、对白与主次关系 | 本次主体超过5人时优先清晰独立视图；不把全部角色母版/Look重复上传 |
| 人物与声音绑定 | 三 → 音色参考升级；打破语言边界 | 区分人物、音色、台词内容、口音及音频用途 | 建立角色—音色映射；对白/字幕/画内字语言分别指定，局部例外显式说明 |
| 只迁移创意/视听结构 | 三 → 迁移创意 | 抽取参考的结构、表演、机位、剪辑或节奏，替换主体外观 | 写明参考和排除维度；不照搬原人物、品牌、场景，不虚构权重 |
| 局部时段借用动作 | 二 → 白模怎么写？；糖果厨房 boss fight | 布局视频不管动作，动作视频只管成片20–25秒；前一段落点连接下一段 | 引用包记职责、排除项、目标区间；只在确需截取源片时另填源区间，保持连续空间状态 |
| 保留开局继续讲 | 二 → 视频延长怎么写？；三 → 视频延长；战士警觉/换游侠、三人战龙 | 一镜到底与切镜两条连接方式，新增剧情可改变场景或角色 | 分别记源片/新增/最终时长；新增段从0秒编排，保持项不抵消允许变化 |
| 精确局部改物 | 二 → 智能编辑与高级编辑/视频编辑；三 → 局部消除与编辑 | 目标、A→B、生效时序；有标注时加工具、区域内外和帧标签 | 改什么与不改什么分开；检查局部完成后是否影响后续帧或无关物体 |
| 去音乐但保留现场 | 三 → 分离/移除背景音乐 | 音轨职责分离，明确要保留的对白/环境声/音效 | 用音频编辑子协议；不重建角色图，不把去BGM改成静音或删除字幕 |
| 改观察角度 | 三 → 空间视角修改 | 保留场景世界关系，改相机观察位置 | 写新视角及可变投影/遮挡；删除“原机位和所有像素不变”等冲突保持项 |
| 换背景 / 绿幕合成 | 三 → 无缝绿幕编辑 | 背景替换、输出绿底、前景放入背景是不同任务 | 区分前景/背景源、时序、比例、落点、遮挡、光照及边缘，不承诺Alpha |
| 粗白模动态重创作 | 二 → 白模怎么写？；精灵女王、小狗；三 → 专业级白模控制 | 简单代理控制空间/动态，用目标资产替换外观 | 明确每个几何代理对应谁；有肢体就补动作链，避免僵硬照抄 |
| 完整动画精细渲染 | 二 → 白模怎么写？；古战场、香水广告 | 保留有用动画/机位，分段指定材质、场景、光影 | 与粗白模分开写；清理辅助轨迹和坐标轴；产品名/水果/Logo保持一致 |
| 两端内容转场 | 二 → 视频延长怎么写？的转场表；三 → 视频无缝转场 | 转场类型 + 必要约束 + 两端叙事/运动连接；允许模型从候选中选择 | 低精度不给过多机械细节；高精度补切点与匹配；生成桥接不等于无损剪辑 |
| 以画面计划驱动分镜 | 三 → 多宫格分镜 | 一格一完整镜头，线稿表达构图、人物与动作，模型补中间过程 | 明确格序、最终画风及角色参考；不误生固定分屏，不将某格当成单独人物图 |

首帧/首尾帧来自“二 → 参数设定 / 功能交互”的明确入口支持：适合锁定起止构图的任务。不要为了收集 Good Case 而声称每个支持项都有本项目观看验证过的成功案例。

## 2. 三个迁移示例（本 Skill 自拟，非官方原文）

### 表演：给变化，不给全程静态情绪

“开场她仍在等一个答复，听见关门声后才移开目光。短促地笑一下又收住，像在努力维持体面；直到脚步声远去才放松紧握的手。结尾停在释然但没有笑容的脸上。全片克制，无旁白和BGM。”

适合节拍驱动；若要求落泪恰在某秒，再加局部时间控制，而不是默认复制29秒告别案例。

### 引用：让不同素材各管一件事

“@视频1仅提供骑士与巨兽的尺度、站位和机位距离，不复制其动作。@视频2仅为本片20–25秒反击段提供起跳和挥击节奏，不用于其他段；人物、武器和场景用各自图片参考。反击从前段落地位置继续，不重置双方位置。”

实际交付还需逐一映射已上传图片；此处只示范范围控制，不能把未映射的“各自图片”原样当作完整可执行包。

### 续写：允许换景，但不丢连接依据

“从原片末尾追加10秒，以下0秒为新增段起点。原片女子关门的动作完成后，以门合拢的声音切入次日车站；同一身份，改用已批准的旅行Look。她放下与前片相同的手提箱，抬头看向进站列车。新场景使用车站环境声，不重复关门动作。”

不是要求门声贯穿车站全段，也不是要求原片衣服永远不变。

## 3. 案例中的冲突与不应泛化的要求

| 原文问题 / 位置 | 复用前的处理 |
| --- | --- |
| 超长咖啡馆例同时写“仅自然白噪音”和钢琴BGM | 问清声音选择；不可自动把两者都放进最终包 |
| 语言示例全局指定马来语，局部又给英语/西语对白 | 判断是否有意保留外语例外；全局规则限定范围，不擅自改台词 |
| 电商/穿搭例要编号/标签，又要求无文字 | 拆分画内标签、品牌字、字幕和额外说明文字，写允许清单 |
| 战士换游侠续写正文新增10秒，表内“延长15s”与15–25s又不一致 | 以用户本次目标重新核算 S、N、S+N，不照抄示例表的矛盾数值 |
| 江边告别时间切片之间有未显式覆盖的区间 | 迁移为完整时间轴时补足延续/停顿，不凭空插入新事件；采用节拍时不伪装完整逐秒表 |
| 白模香水渲染例水果称谓前后不一 | 先统一产品/物体身份；材质修辞不能掩盖对象变化 |
| 示例用4K/8K/60fps或“像素级/完美/无损”描述目标 | 和正式输出参数分开；要求可写，能力与执行结果不能据此承诺 |
| 局部消除例2.5评价提及帽子意外掉落 | 验收修改范围外与后续帧；不据“局部成功”推断整段无副作用 |
| 同一表格有2.0和2.5成片评价 | 按表头与行归属核对，不把旧模型失败抄成2.5必然缺陷 |
| 无硬切、全程同Look、真实物理等在特定示例里成立 | 仅在任务需要时使用；不能禁掉用户的蒙太奇、换装或超现实表达 |
